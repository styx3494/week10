# 節點 7：檢查簡報

1. **事實一致**：逐張比對 `slides/index.html` 與 `outline.md`，找出大綱裡沒有、卻被加進簡報的說法。
2. **實際瀏覽**：在瀏覽器中開啟簡報，確認可以翻頁、手機寬度不會破版，程式碼可以捲動。
3. **初學者測試**：假設你是完全不懂的人，讀完後能不能回答下列問題？
   - Docker 的連接埠對應是什麼？
   - 找不到 NAS 時，第一步應該檢查什麼？
   - 為什麼不建議啟用 SMB1？

輸出問題清單，每一項的處理方式只能是以下三種之一：

- `改簡報`：回到節點 6。
- `改大綱`：回到節點 4。
- `通過`

把結果記到 `wiki/log.md`。

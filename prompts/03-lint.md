# 節點 3：Lint（檢查 Wiki）

請檢查 `llm-wiki/wiki/` 的所有頁面，**先只回報，不要修改**：

| 檢查項目 | 不合格的情況 |
|---|---|
| 來源 | 「重點」裡有沒有標註來源的句子 |
| 來源真實性 | 標註的 raw 檔案裡找不到那句話的依據（請逐點對照原文） |
| 一句話說明 | 比喻或摘要中出現「重點」沒有的事實（例如自行加上「舊 NAS」）。這一欄沒有標註來源，最容易混入推測（2026-11-16 新增） |
| 連結 | `[[slug]]` 指向不存在的頁面 |
| 目錄 | `index.md` 漏掉某頁，或列了不存在的頁 |
| 矛盾 | 兩頁說法互相衝突，卻沒有寫進「待確認」 |
| 孤兒頁 | 沒有任何頁面連到它 |
| 初學者可讀性 | 「一句話說明」用了沒有解釋的術語 |

輸出一張表：頁面、問題、建議修法、嚴重程度（必修／建議）。

我確認之後你再修正，並在 `log.md` 記錄 lint 的結果與修正內容。若有「必修」項目，修完後重跑一次 lint。

# Docker 網路基礎

## 一句話說明

每個容器都以為自己有一張普通的網卡；Docker 在背後幫它接上一個虛擬網路，最常見的是「bridge」。

## 重點

- 容器預設就有網路，可以主動對外連線。（來源：raw/02）
- 容器只看到一張網卡，上面有 IP、閘道、路由表與 DNS；它不知道自己接的是哪一種網路。（來源：raw/02）
- Linux 上的 Docker Engine 第一次啟動時，會有一個內建的「default bridge」網路；`docker run` 沒有指定 `--network` 時，容器就接在這裡。（來源：raw/02）
- default bridge 上的容器透過 masquerading 對外連線：只要主機能上網，容器就能上網。（來源：raw/02）
- default bridge 上的容器彼此只能用 IP 互連，不能用名稱；接在使用者自訂的網路上時，可以用容器名稱互連。（來源：raw/02）
- 常見驅動：`bridge` 是預設驅動；`host` 會移除容器與 Docker 主機之間的網路隔離。（來源：raw/02）

## 常見誤解

- 誤解：容器能上網，代表別人也能連進容器。　實際上：對外連線預設可行，但從主機外面連進來，必須先發布連接埠。（來源：raw/02、raw/01）

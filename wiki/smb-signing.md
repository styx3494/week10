# SMB 簽章（Signing）

## 一句話說明

SMB 簽章像是在每個封包上蓋章，確保內容沒有在路上被竄改；Windows 11 24H2 起預設一定要蓋章，不支援簽章的 SMB 伺服器就可能連不上。

## 重點

- Windows 11 24H2、Windows Server 2025 與之後的版本，預設要求 SMB 簽章。（來源：raw/03、raw/04）
- 這可能讓 Windows 連不上工作群組電腦、訪客驗證的共用，或不支援簽章的第三方 SMB 伺服器。（來源：raw/04）
- 改變啟用哪些 SMB 版本，**不會**改變簽章要求。（來源：raw/04）
- 不要用停用 SMB 版本或停用簽章的方式繞過；應在遠端伺服器啟用簽章，或更新／更換不支援簽章的裝置。（來源：raw/04）
- 訪客登入不支援 SMB 簽章與加密。（來源：raw/03）

## 常見誤解

- 誤解：升級到 Windows 11 24H2 後連不上 NAS，把 SMB1 打開就好。　實際上：簽章要求與 SMB 版本無關，打開 SMB1 不會解決。（來源：raw/04）
